# MSc Applied Data Science and Statistics: Coursework

My coursework and practical work from the MSc Applied Data Science and Statistics at the University of Exeter (2024–25), in Python and R. My dissertation is in a separate repository: [msc-dissertation](https://github.com/bengoodwin625/msc-dissertation).

## Python: `python/`

| Notebook | What it covers |
|---|---|
| `MTHM503 - Applications of Data Science and Statistics.ipynb` | Assessed coursework: PCA on a gene-expression dataset, regression modelling of sea-level change, and hierarchical clustering of power-demand profiles |
| `Week 1 - traffic problem set.ipynb` | pandas data wrangling on UK road traffic accident data (2019) |
| `Week 2 - gapminder problems.ipynb` | Visualising life expectancy and GDP data from Gapminder (plotnine / Matplotlib) |
| `Week 3 - handwritten digits problem.ipynb` | Dimensionality reduction on the scikit-learn digits dataset |
| `Basic python - week 1.ipynb`, `Test online.ipynb` | Python fundamentals and pandas practice |

> `gene_file.csv` (108 MB) is over GitHub's file-size limit, so it isn't included. The MTHM503 notebook needs it to re-run Section A.

## R: `r/`

| Folder | What it covers |
|---|---|
| `modelling-in-space-and-time/` | Assessed coursework for *Modelling in Space and Time*: time-series modelling of sea surface temperature and spatial modelling of maximum temperatures in California |
| `advanced-topics-schizophrenia-reaction-times/` | MTHM017 *Advanced Topics in Statistics* project: statistical modelling of reaction-time data and a classification task |
| `tb-spatial-modelling/` | Spatial modelling of tuberculosis rates against socio-economic covariates (GAMs, `mgcv`) |
| `practicals/` | Weekly practicals: data wrangling, regression, Bayesian modelling with JAGS, and more |

Some R scripts load module datasets (for example `datasets.RData`) that were provided on the course page and aren't included here.

**Tools:** Python (pandas, NumPy, scikit-learn, PyTorch, SciPy, seaborn, plotnine), R (tidyverse, mgcv, R2jags, ggplot2), Jupyter, Quarto / R Markdown
